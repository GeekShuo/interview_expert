# 我刚刚经历的AI面试

> 互动: {'likes': 417, 'comments': 63} | 命中关键词: ai模拟面试

趁着脑袋还清醒，赶紧总结出来。我是第一次接触AI面试，昨天接到面试短信后，临时抱佛脚，在知乎上查了一些，感觉相关内容还是少。今天亲身经历了，把内容分享给大家，以期对你们有所帮助。1、你对报考岗位的了解，你自身报考该岗位的优势。2、关于政策和规则，有人说按部就班照做，有人说只是有一定的指导性，谈谈你的看法。3、你做的坚持最久的一件事，从这件事收获到了什么。4、谈谈在工作中遇到的一次危机，谈谈你是怎么做的。每道题回答之前有10秒钟的思考时间。10秒倒计时之后，有一个和蔼的智能机器人一直盯着你，向你点头示意，这点设置挺好的，回答问题看镜头不至于太尴尬，点头可以看作一种鼓励，一种交流。每道题的回答会限制时间，两分钟或者三分钟。回答完可以点提交答案；如果超时，系统自动回收答案。我回答第四道题超时了，没有说完。剩下的就是做一些选择题。结果还不知道，等出来的话，再更新了。
