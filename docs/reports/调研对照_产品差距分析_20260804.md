## 一、调研验证了项目做对了什么

1. **「结合简历/JD 个性化」正是免费工具的死穴** — 知乎实测者对免费竞品的原话："基本是通用模板，不会结合你的简历"。简历解析 + 可追问点清单正是已建成的能力，方向押对了。
2. **真实判题是独家差异** — 实测者明确说"算法题 AI 帮不上忙"；豆包/DeepSeek DIY 玩法完全没有代码判题。Docker 沙箱判题是所有"提示词平替"给不了的。
3. **评分拆维度 + 引用原文证据，符合从业者标准** — 智蛙三硬指标之一"评分拆维度、能复盘、拒绝黑箱总分"，报告已做到（维度 + 证据引用），此项达标。

## 二、调研照出来的不足（代码审查看不到的）

4. **没有「限时」机制 = 不是真面试** — 智蛙第一硬指标："语音出题、**限时思考**、开口作答，对着屏幕打字没用"。当前系统是无限时纯文字对话；TODO 里"时间感"只被当作 P2 打磨项，但调研显示它是**真实感的核心**，优先级应上调。
5. **追问仍是「搜索框」而非「Agent」** — 智蛙分水岭原话："能记住你、针对你这一遍作答来回讲的才是 Agent，只会吐标准答案的是搜索框"。从用户视角独立印证了代码层结论（追问靠单 prompt 自由发挥，无策略节点）。**这是调研和代码两边指向的同一个最大短板。**
6. **评分没有「规则治理」，只有 prompt** — 智蛙："好评分靠的是评分规则治理，不是接个模型就行"。当前评分标准全在 prompt 文本里，没有结构化 rubric（表现↔档位映射、扣分项清单），评分稳定性完全看模型发挥——会让「成长曲线」（北极星指标）分数漂移、不可信。
7. **缺一类被验证的爆款场景：企业 AI 面专项模拟** — 最硬的倒逼证据：安踏/瑞幸/优衣库 UMC/海纳 AI 已把 AI 面放进校招第一轮，形态是"对屏幕答题、限时、无真人反馈、无追问"。当前产品只模拟**真人风格**面试官（有来有回），没有模拟**企业端 AI 面试官**形态（单向出题、限时录制式、无追问、按答题完整度打分）。需求最旺、面经满天飞、恰好没覆盖。
8. **英文面试模式是低成本高需求扩展** — "用 AI mock 英文面试后强到可怕"互动 1.9 万，头部内容。LLM 链路切换语言几乎零成本（persona + prompt 出英文版），当前无英文模式。
9. **效果无法自证 = 没有营销弹药** — 调研共识："所有好评都是个人体感，谁先拿出效果数据谁有最强卖点"。呼应 inspect.md 的"北极星指标无埋点"——不埋点，永远攒不出"用户平均分提升 X 分"这个最值钱卖点。

## 三、调研给出的商业化校准

10. **定价敏感信号明确** — 用户对 109 元/月订阅敏感、认为 69.9 永久划算；建议**按场景包/次数包**，订阅制谨慎。TODO 里"免费 N 场 → 深度报告收费"方向与此吻合，可进一步设计为"场次包 + 单项深度报告买断"。
11. **叙事必须诚实** — 从业者反复强调"AI 替代不了临场压迫感，解决的是练够量 + 每次稳定反馈"。着陆页（未做）文案应主打"随时练、每次都稳、指出你哪里不对"，而非"保过/替代真人"——后者正是被测评作者群嘲的夸大宣传话术。
12. **合规红线已有行业教训** — OfferGo 类"实时提词"（双端隔离、109/月）已被差评君公开质疑，从模拟滑向实时作弊只有一步。调研建议"守住练习定位"——当前定位正确；再次印证小程序文案规避"面试/求职"红线的必要性。
13. **B 端白标是被验证的退路** — 智蛙靠"给小培训机构白标 AI 陪练"活了三年（小机构自研需几十万 + 教研团队）。当前架构（多用户隔离 + tier + 按账户分区）离白标只差"机构管理后台"，C 端若起不来，这是已验证的 B 端出口。

## 四、值得深挖（按投入产出比排序）

| 优先级 | 方向 | 依据 |
|---|---|---|
| ★★★ | **追问策略节点 + 评分 rubric 结构化** | 从业者三硬指标里缺两个半，"Agent vs 搜索框"分水岭 |
| ★★★ | **限时机制 + 时间感**（思考倒计时、作答计时、报告加"时间控制"维度） | 从业者认证的真实感核心，改动量小 |
| ★★☆ | **企业 AI 面模式**（单向出题 + 限时 + 无追问 + 录像感 UI） | 调研中需求最旺的新形态，与现有状态机互补而非重写 |
| ★★☆ | **英文面试模式** | 头部内容验证的需求，纯 prompt/persona 层改动 |
| ★☆☆ | **反模板/反同质化追问**（识别背诵腔、模板化回答并动态换角度） | 调研指出"目前几乎没人讨论"，提前布局的下一代壁垒 |
| ★☆☆ | **效果埋点**（为"平均分提升 X 分"卖点攒数据） | 营销最强弹药，同时支撑北极星指标 |

## 五、一句话总结

代码审查（inspect.md）回答"房子有洞要补"；这批调研回答"房子的朝向对不对"——
方向（个性化 + 判题 + 可解释评分）被市场验证是对的，但距离从业者定义的"合格 AI 面试产品"
还差三样：**限时、真追问、规则化评分**，外加一个被竞品漏掉的大场景（企业 AI 面模拟）。
